Como funciona a dedução?

Cada registro que você arquiva vira um exemplo de treino: um nome de causa + as palavras que descrevem quando ela acontece. Ao consultar, o texto digitado é comparado, palavra por palavra e em pares de palavras (bigramas), com cada causa cadastrada, usando um classificador estatístico simples (Bayes ingênuo). O resultado é uma porcentagem relativa de o quanto os fatos descritos combinam com cada causa conhecida.

O sistema só conhece o que você ensinou a ele. Poucos registros geram palpites fracos; uma base maior e variada gera deduções mais afiadas.

Todos os dados ficam salvos apenas neste navegador, via IndexedDB — nada é enviado para fora. Exporte periodicamente um backup em JSON pelo botão "Exportar".
